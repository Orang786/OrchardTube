# OrchardTube

Клон YouTube с оранжевым характером: фронтенд на чистом HTML, CSS и JavaScript (без сборки), бэкенд на Express + MongoDB.

## Запуск

Открыть `index.html` в браузере **или** поднять локальный сервер (нужен Node.js):

```
node server.js 8777
```

Затем открыть [http://127.0.0.1:8777](http://127.0.0.1:8777).

Без `MONGODB_URI` сайт работает на демо-данных из `js/data.js` (комментарии и лайки живут в `localStorage`), загрузка видео отключена.

## Режим с базой данных

1. Скопируйте `.env.example` в `.env` и укажите `MONGODB_URI` (например, MongoDB Atlas).
2. `npm install`
3. `npm run seed` — загрузить демо-данные в базу (стирает коллекции channels/videos/shorts/comments).
4. `npm start`

Что включается: комментарии, лайки, подписки и просмотры сохраняются на сервере; работает **загрузка видео** (окно «Создать → Загрузить видео»), настоящий плеер, превью-кадр и удаление своих видео («Ваши видео»). Файлы хранятся в MongoDB GridFS, раздаются с поддержкой перемотки (Range).

> Аккаунтов в проекте пока нет, а загрузка идёт от имени канала OrchardTech. Поэтому **обязательно задайте `UPLOAD_TOKEN`** на публичном сайте: без него загружать и удалять видео сможет любой посетитель. Ключ вводится в форме загрузки.

## Деплой на Render

В репозитории есть `render.yaml` (Blueprint). Создайте Blueprint из репозитория, задайте `MONGODB_URI`; `UPLOAD_TOKEN` сгенерируется сам (виден в панели Render). Бесплатный Atlas — 512 МБ на всё, поэтому лимит `MAX_UPLOAD_MB` по умолчанию 100.

## API

| Метод и путь | Назначение |
|---|---|
| `GET /api/health` | режим (`mongodb`/`demo`), доступна ли загрузка |
| `GET /api/bootstrap` | каналы, видео, шортсы, комментарии |
| `POST /api/videos` | загрузка (multipart: `title`, `desc`, `category`, `duration`, `thumb`, `video`); нужен `x-upload-token`, если задан `UPLOAD_TOKEN` |
| `DELETE /api/videos/:id` | удалить загруженное видео (только пользовательские) |
| `GET /api/media/:id` | файл видео/превью (Range) |
| `POST /api/videos/:id/view`, `/like` | счётчики просмотров и лайков |
| `POST /api/comments` | новый комментарий |
| `POST /api/channels/:id/subscribe` | счётчик подписчиков |

## Что внутри

**Страницы**
- Главная: сетка видео, лента Shorts, чипы категорий
- Просмотр: плеер с прогрессом, лайки, подписка, описание, комментарии, похожие видео
- Канал: баннер, вкладки «Видео / Shorts / Плейлисты / О канале»
- Shorts: лента и страница отдельного шорта
- Подписки, Библиотека, История, Понравившиеся, Смотреть позже, Ваши видео
- Плейлисты, поиск с результатами, демо-страницы Premium / Music / Детям

**Возможности**
- Тёмная и светлая темы (переключатель в меню, `T`)
- Поиск по названиям, каналам и описаниям с автодополнением (подсказки при вводе)
- Подписки, лайки/дизлайки, «Смотреть позже», история — сохраняются в `localStorage`
- Добавление комментариев, лайки комментариев, сортировка (популярные / новые)
- Контекстные меню видео, меню профиля, уведомления
- Модалки «Загрузить видео», «Настройки», «Справка»
- Горячие клавиши: `/` поиск, `K` или `Space` пауза, `T` тема, `Esc` закрыть, `?` справка
- Адаптив: полное меню → мини-рейл → мобильное выдвижное меню

## Структура

```
index.html        разметка каркаса
css/styles.css    все стили и дизайн-токены
js/icons.js       SVG-спрайт иконок
js/data.js        демо-данные: каналы, видео, шортсы, комментарии
js/app.js         роутер на hash, рендер страниц, вся интерактивность
server.js         Express: REST API + раздача фронтенда (только index.html, css/, js/)
db.js             слой данных: MongoDB + GridFS или демо-режим
seed.js           загрузка демо-данных в MongoDB
render.yaml       Blueprint для деплоя на Render
```

## Роутинг

Хеш-роутер, работает и с `file://`:

`#/`, `#/watch/:id`, `#/channel/:id/:tab`, `#/shorts/:id`, `#/search?q=`, `#/library`, `#/history`, `#/liked`, `#/watch-later`, `#/my-videos`, `#/playlist/:id`, `#/premium`, `#/music`, `#/kids`
